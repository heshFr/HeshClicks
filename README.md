# 🦋 HeshClicks v1.0

HeshClicks is a Python automation suite with autoclickers, keyboard typing, macro recording, hotkey rebinding, Compact+ mode, and theme packs — all in one clean GUI.

---

## 🚀 How to Install and Run (VS Code Instructions)

1. **Download Python**

2. **Download this project**

🎮 Default Hotkeys
- Start Left Clicker → f6
- Start Right Clicker → f7
- Type Text → f8
- Record Macro → ctrl+shift+m
- Stop Macro → ctrl+shift+s
- Play Macro → f9
- Compact Mode → ctrl+shift+c
- Stop All → ctrl+esc
